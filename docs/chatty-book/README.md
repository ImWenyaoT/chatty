# Chatty Book

Chatty 是一个中文电商推荐 Agent。用户可以直接说“我要一个 300 元的蓝牙耳机”，Chatty 会理解预算和类目，查询用户画像、商品、库存与知识，最后给出经过事实校验的推荐。

这本书从一次请求出发，逐步解释 Chatty 如何工作，以及为什么代码被组织成现在的样子。阅读不需要预先了解 AI Agent；涉及的新概念都会在出现时说明。
